04 קובץ התקנה למחשב אחר

קובץ אמיתי להורדה — להעברה למחשב שני (Windows / Mac / Linux).
⤓ הורדת חבילת ההתקנה (ZIP)
  1. מעבירים את ה-ZIP למחשב השני (מייל לעצמך / דיסק / Drive) ומחלצים.
  2. עם Docker: docker compose up -d
  3. בלי Docker (Node.js 20+): לחיצה ימנית על install\install.ps1 ← Run with PowerShell, ואז npm start
  4. פותחים http://localhost:4420/daily.html ומגדירים ב"הגדרות" את התיקיות של אותו מחשב.

המערכת רצה על המחשב בלבד. ההורדה כאן היא של הקוד + פרטי הלידה + הגדרות צ'אט AI. בלי מפתחות API ובלי מטמונים.

05 התקנה בטלפון (אפליקציה)

סורקים מהטלפון — נפתח בדפדפן, ואז "הוסף למסך הבית". הטלפון חייב להיות על אותה רשת Wi-Fi כמו המחשב.
2 · בטלפון, פְּתַח את הכתובת בכרום / ספארי (או סרוק QR):
…
  1. הזיפ לא מיועד לטלפון — בטלפון לא מתקינים קובץ. פותחים את הכתובת למעלה בדפדפן.
  2. אחרי שהעמוד נטען בטלפון: תפריט הדפדפן ← "הוסף למסך הבית" / "Add to Home Screen". נוצר אייקון אפליקציה.
  3. תן לאפליקציה 10 שניות עם חיבור בפעם הראשונה — משם היא עצמאית וגם עובדת במצב טיסה.
  4. אם לא נטען אחרי כפתור 1 — בדקו בראוטר שאין "בידוד לקוחות" / "AP Isolation", ושהטלפון על אותה רשת Wi-Fi.

עצמאי בכל מכשיר. אחרי התקנה ראשונה, האפליקציה בטלפון עובדת גם כשהמחשב כבוי וגם מחוץ לרשת: המענה היומי (תאריך עברי, פרשה, תהילים, ספירה לחג), הקריאה (הגדה / מגילה / תהילים), מחשבון הכספים והדיבוב הקולי — הכל מחושב במכשיר עצמו. נתוני שוק, לוטו וסיכום ה-AI מוצגים מהעדכון האחרון שנשמר. עיצוב וידאו AI ו-DevOps נשארים במחשב.

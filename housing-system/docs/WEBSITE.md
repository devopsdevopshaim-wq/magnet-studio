# WEBSITE — שכבת האתר (שלב הבא)

האתר הוא לקוח דק מעל WF04. אין בו לוגיקה עסקית — הכול דרך ה‑API.

## סטאק מוצע
- **Next.js (App Router) + TypeScript**, Tailwind, shadcn/ui.
- מפה: MapLibre + אריחי govmap / OpenStreetMap; שכבת תב"ע כ‑WMS מ‑iplan.
- קריאת נתונים: `GET /webhook/search` וכו' דרך route handler בצד שרת (מסתיר את `PUBLIC_API_TOKEN`).
- אימות משתמשים: Auth.js (אם רוצים פרופילים שמורים / מועדפים) — נשמר ב‑Postgres.

## מסכים
| מסך | API | תיאור |
|---|---|---|
| חיפוש | `GET /search` | פילטרים (עיר, מחיר, חדרים, מרוהט, מכר/שכירות, מדינה) + מיון לפי ציון; כרטיסי נכס עם ₪/מ"ר ופער מהשוק |
| נכס | `GET /listing/:id` | הערכת שווי, דגלים אדומים, מגורים/השקעה, כפתור "בדוק מצב תכנוני" ו"הוסף להשוואה" |
| השוואה | `POST /compare` | טבלת ההשוואה + המלצת הסוכן + תרחישים |
| מחשבון משכנתא | `POST /mortgage/evaluate` | טופס: הכנסת בן+בת זוג, הון, התחייבויות, גיל, מטרה → מחיר מקסימלי, החזר, מבחן לחץ, תמהיל, נכסים בתקציב |
| מתאר / מפה | `GET /area/:id/plan` | שכבות תב"ע, ייעוד, זכויות, תמ"א/פינוי‑בינוי, בנייה עתידית |
| "איפה לגור" | `POST /areas/match` | אשף פרופיל → אזורים מדורגים |
| עוזר | `POST /assistant` | צ'אט שמריץ את כל היכולות; שומר `sessionId` ב‑cookie |

## הערות מוצר
- כל מסך כספי/תכנוני מציג את ה‑disclaimer מהסוכן.
- שמור `sessionId` יציב בין המחשבון, החיפוש והצ'אט → העוזר "זוכר" את הפרופיל.
- אין איסוף פרטי אשראי/ת"ז באתר. למחשבון מספיק טווחי הכנסה.

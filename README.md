# חיים קריספין - מערכת הפעלה מתקדמת

אתר מקומי אחד (רץ על המחשב שלך בלבד) שמאגד את הכל: **מענה יומי** אוטומטי בהפעלת המחשב,
עוזר **JARVIS** (צ'אט רב-סוכנים מול n8n), פאנל **דיור** (DiraFinder), ניהול עיצובי מגנטים
לאירועים ועורך מסגרות, מיילים, יומן, לוח שנה עברי, מצב המחשב, אבטחה, ו-Maton.

> **המערכת רצה על המחשב בלבד.** אין ענן, אין PWA, אין גישה מהטלפון — הכל מול `http://localhost:4420`.
> נקודת הכניסה בהפעלת המחשב: `daily.html` (אוטוסטארט). התקנה על מחשב אחר: [`INSTALL.md`](INSTALL.md)
> (Docker בפקודה אחת, או Node ישיר) + גיבוי/ייבוא הגדרות דרך "הגדרות" סעיף 03.

## מענה יומי (`/daily.html`)

נפתח אוטומטית פעם ביום בהפעלת המחשב (דרך `run-hidden.vbs`). עמוד אחד ארוך עם עוגני-ניווט למעלה:

- **נרטיב "בוקר טוב"** רב-פסקאות שנכתב ב-AI מעל כל השאר, ומשלב את הכל: היום המעשי, הלימוד היומי,
  השמיים והמזל, ומצב המערכת + המלצה. מקורות לפי סדר זמינות: (1) ה-workflow של JARVIS ב-n8n Cloud
  (לא דורש כלום מקומי); (2) Ollama מקומי; (3) ספק ענן אם מוגדר מפתח. אם אין מקור — מוצג רק המידע המובנה.
- **מבט מהיר** — אירועי היום/מחר, מיילים שלא נקראו, מגנטים שממתינים לעיצוב, התראות n8n, אבטחה, דיור.
  כרטיס המיילים מקבץ **"חיפוש עבודה" מול "אחר"** ומראה את התחומים המקצועיים שזוהו (DevOps / Cloud / Data /
  Backend / Frontend / QA / מוצר / UX / IT / אבטחה / מכירות). דיור מציג שם + טלפון של המפרסם (`tel:` ללחיצה) ו"תיווך".
  אם מפתח ה-Maton פג — מוצגת אזהרה עם ההוראה `setx MATON_API_KEY`.
- **ניהול היום** — 3 המלצות מעשיות מתחלפות כל יום (תזונה · תנועה · שינה · ריכוז · נפש · ...), מתוך `data/daily-tips.json`.
- **היומן השבוע** — 7 ימים קדימה, אירועים לכל יום, תגית צבע לכל חשבון (ראו "יומן משני חשבונות" למטה).
- **הגרלה קרובה** — מתי ההגרלה הבאה (יום ג'/שבת), ההגרלה האחרונה, מספרים חמים/קרים, ו-3 טורים משוקללים
  לפי היסטוריית מפעל הפיס. **לא תחזית** — כל צירוף שווה בהסתברות.
- **הלימוד היומי** (דרך Sefaria API) — משנה יומית, תניא יומי (קבלה), הלכה יומית — עם הטקסט המלא
  והסבר קצר בעברית שנכתב ב-AI; וגם דף יומי, תנ"ך 929, חוק לישראל.
- **פרשת השבוע** — שם, תקציר, עליית היום (יום א'=ראשון … שבת=שביעי), הפטרה.
- **פתגם היום** — מסתובב לפי היום בשנה מתוך `data/proverbs.json`.
- **השמיים היום** (חישוב מקומי, `astronomy-engine` + `@hebcal/core`) — זמנים הלכתיים, אורך היום
  ושינוי מאתמול, מופע הירח ואחוז הארה, כוכבי לכת נראים אחרי השקיעה.
- **זמני שבת** (`lib/shabbatClient.js`, `@hebcal/core`) — כניסת ויציאת השבת הקרובה (או של עכשיו אם שבת),
  פרשת השבוע, וערבי חג סמוכים. המיקום נלקח מ-`data/astro-config.json` (רחובות וכו') או ירושלים כברירת מחדל.
  גם בכרטיס קטן בלוח הבקרה (`/api/shabbat`).
- **המזל היום** — אסטרולוגיה אישית לפי מפת לידה. בפעם הראשונה מזינים תאריך/שעה/עיר לידה (טופס בעמוד)
  → נשמר ב-`data/astro-config.json`, **כל החישוב מקומי, שום דבר לא נשלח לאף שירות**. מציג מפת לידה
  (מזלות, אופק, בתים), "מזל היום" (שמש+ירח), וטרנזיטים/היבטים בולטים מול המפה. עם **בוחר תאריך** —
  משנים תאריך והטרנזיטים + **הסבר מילולי מלא בעברית לכל היבט** (מ-`data/astro-meanings.json`) מתעדכנים מיד
  (`GET /api/astro/reading?date=YYYY-MM-DD`, בלי AI). פענוח מעמיק — בלשונית "אסטרולוגיה".
- **מצב המערכת (מורחב)** — זיכרון/דיסק/מעבד/טמפ'/סוללה/תהליכים, כל הכוננים, רשת ואינטרנט
  (מתאם, IP מקומי/חיצוני, זמינות n8n/Ollama/Maton), אתחול ועדכון Windows אחרונים, המלצות.

הכל נשמר במטמון יומי (`data/daily-brief-YYYY-MM-DD.json`); כפתור "רענן" (או `?refresh=1`) מייצר מחדש —
כולל נרטיב, הסברי לימוד וטרנזיטים חדשים. הייצור הראשון ביום עשוי לקחת ~30-60 שניות (קריאות Sefaria + AI).

## n8n מקומי + סטאק DiraFinder (Docker)

בעליית השרת, magnet-studio מנסה (best-effort, לא חוסם) להרים:
- **magnet-studio-n8n** — `n8n/docker-compose.yml`, פורט 5680, ללא סיסמה. אם כבר רץ — מדלגים.
  (JARVIS עצמו נשאר מול n8n Cloud; ה-n8n המקומי לשימוש חופשי.)
- **סטאק DiraFinder** — `../housing-system/infra/docker-compose.local.yml` (`--env-file .env.local`),
  Postgres בלבד על פורט 5433, עם `schema.sql` + `seed.sql` (40 נכסי דמו) שנטענים אוטומטית.
  לשונית "דיור" מציגה את הנכסים מה-Postgres הזה. עם n8n משלו: `--profile full`.

צריך ש-Docker Desktop יהיה פתוח. בלוח הבקרה, סקשן n8n — שורת סטטוס + כפתורי "פתח" / "הפעל".
בלשונית דיור — פס סטטוס + "הפעל סטאק".

## צ'אט קולי ל-JARVIS

בראש לשונית JARVIS מוצגות **פני העוזרת** — רכיב SVG מצויר (`public/js/avatar.js`) שנושם, ממצמץ,
נוטה את הראש כשהוא מקשיב, מביט הצידה כשהוא חושב, ו**מזיז את הפה לפי עוצמת הקול בזמן אמת** בזמן הקראה
(Web Audio `AnalyserNode` על ה-`<audio>`). פרצוף קטן מופיע גם ליד הברכה במענה היומי.

בלשונית JARVIS: כפתור 🎤 + כפתור **"מצב קול"** במחזור 3 מצבים (נשמר):
- **כבוי**
- **הקראה** — התשובות מוקראות בקול.
- **שיחה רציפה** — אחרי כל תשובה המערכת מקשיבה שוב אוטומטית. כמו שיחה עם אדם: מדברים, מקבלים תשובה
  בקול, ממשיכים לדבר — בלי ללחוץ שוב על המיקרופון.

זיהוי דיבור: Web Speech API של הדפדפן (`he-IL`, כרום).

**קול נשי (`/api/tts` בשרת):**
1. אם מוגדר `AZURE_SPEECH_KEY` (+ `AZURE_SPEECH_REGION`) → **Microsoft "Hila" Neural** — קול נשי אנושי מאוד.
2. אחרת → Google Translate TTS (קול נשי עברי סביר, ללא מפתח).
3. אם השרת לא נגיש → `speechSynthesis` של הדפדפן (הקול המקומי, מעדיף נשי).

```powershell
setx AZURE_SPEECH_KEY "המפתח-מ-Azure-Speech"
setx AZURE_SPEECH_REGION "westeurope"
```

## JARVIS מקומי — `n8n/workflows/jarvis-local.json`

`/jarvis.html` מכוון **כברירת מחדל ל-n8n המקומי** (Docker, פורט 5680), לא ל-Cloud.
ה-workflow `jarvis-local.json` (Webhook → מושך `/api/daily-brief` + `/api/calendar/week` → בונה prompt
עם הקשר היום → Ollama `llama3.1:latest` → `{output}`) **מיובא ומופעל אוטומטית** בעליית השרת דרך
ה-CLI של n8n בתוך הקונטיינר (`n8n import:workflow` — לא צריך owner account ולא API key).

- להחלפת מודל: בצומת "Build Ollama Request" ב-workflow, שנו `llama3.1:latest` ל-`gpt-oss:120b-cloud`
  (איכות עברית טובה בהרבה). llama3.1 המקומי חלש ואיטי (~30ש' לתשובה).
- למעבר בין מקומי ל-Cloud: `/jarvis.html` → ⚙ הגדרות → "יעד" (n8n מקומי / n8n Cloud).
- הנרטיב וההסברים במענה היומי **לא** עוברים דרך JARVIS המקומי (זה היה יוצר מעגל — ה-workflow מושך
  את המענה היומי בעצמו) — הם משתמשים ב-Ollama ישירות.

## חיבור Maton (Gmail/Drive/Calendar/Slack/YouTube במקום אחד)

**אזהרת אבטחה חשובה קודם כל:** לעולם אל תדביקו מפתח API בצ'אט עם Claude או בכל מקום אחר שאינו מיועד לכך - זה נשמר בהיסטוריה כטקסט גלוי. אם הדבקתם מפתח בטעות (בצ'אט או בכל מקום), התייחסו אליו כאל חשוף ובטלו/צרו מפתח חדש ב-Settings של Maton.

**התקנה נכונה:**
1. היכנסו ל-[maton.ai](https://maton.ai), עברו ל-Settings, וצרו/העתיקו את מפתח ה-API.
2. הגדירו אותו כמשתנה סביבה **מקומי** במחשב (לא בקובץ בפרויקט, לא בצ'אט):
   ```bash
   setx MATON_API_KEY "המפתח-שלכם-כאן"
   ```
   (אחרי `setx` צריך לפתוח טרמינל חדש כדי שהמשתנה ייטען)
3. הפעילו מחדש את השרת (`npm start` או "הפעלת הסטודיו.bat").
4. בלוח הבקרה, בכרטיס "Maton" בפאנל הצד, לחצו על כל שירות שתרצו לחבר (Gmail/Drive/יומן/Slack/YouTube). ייפתח חלון אישור (OAuth) של Google/Slack/וכו' - זה חד-פעמי לכל שירות.
5. אחרי האישור, רעננו את הדף - הנתונים יופיעו בפאנל.

השרת קורא את המפתח **רק** מ-`process.env.MATON_API_KEY` - הוא לא נשמר בשום קובץ בפרויקט ולא נשלח לשום מקום מלבד ל-api.maton.ai.

## הפעלה

```bash
cd "magnet-studio"
npm install
npm start
```

האתר יעלה בכתובת: http://localhost:4420

## התקנה על מחשב חדש (ניידות)

המערכת אינה תלויה יותר בנתיבים קבועים בקוד. בפעם הראשונה שמריצים אותה על מחשב חדש:

1. `npm install` ואז `npm start` (או הפעלה דרך "הפעלת הסטודיו.bat").
2. האתר יעלה עם באנר "המערכת עדיין לא הוגדרה" בלוח הבקרה — לוחצים עליו, או נכנסים ל-`/setup.html` ("הגדרות" בתפריט).
3. במסך ההגדרות: (א) מזינים נתיב לתיקיית עיצובים אם יש כזו (אופציונלי - אפשר לדלג), (ב) בוחרים מתוך רשימת התוכנות המותקנות במחשב (נסרקת אוטומטית מתפריט ההתחלה) אילו להצמיד להפעלה מהירה.
4. שומרים, ואז מפעילים מחדש את השרת (סוגרים את החלון השחור ומריצים שוב) כדי שההגדרות ייכנסו לתוקף.

כל הגדרה נשמרת בקובץ `data/user-config.json` (לא נכנס ל-git, ספציפי לכל מחשב). ניתן לחזור ל-`/setup.html` בכל שלב כדי לשנות.

**מגבלה ידועה:** מסך ההתקנה מציע לבחירה רק תוכנות שרשומות בתפריט ההתחלה של Windows (כך רוב התוכנות המותקנות כרגיל מזוהות אוטומטית). תוכנות "פורטבליות" שמורדות ידנית לתיקייה בלי התקנה רגילה (כמו PhotoMATE/PhotoScape/Picasa במחשב המקורי) לא יופיעו ברשימה לבחירה, ויש להוסיף אותן ידנית ל-`data/user-config.json`.

## מבנה

- **לוח בקרה** (`/`) — כפתורי הפעלה ל-Lightroom / PhotoMATE / PhotoScape / Picasa 3, גלריית אירועים (נסרקת אוטומטית מתוך תיקיית "עיצובים מגנטים"), סעיף "כל התוכנות במחשב" (סורק את תפריט ההתחלה של Windows ומסווג לקטגוריות), פאנל צד עם מצב מערכת (RAM/דיסק/מעבד) ומצב מיילים, ופאנל אוטומציית n8n.
- **עורך מסגרות** (`/editor.html`):
  - **פריסות קולאז'** — 6 פריסות מוכנות (בודדת/2 אנכי/2 אופקי/3 רצועות/רשת 2×2/מרכזית+2), **ובנוסף גריד מותאם אישית בכל גודל (שורות×עמודות ללא הגבלה)** וגם "תמונה חופשית" להוספת כמות בלתי מוגבלת של תמונות ממוקמות ידנית.
  - **עריכת תמונה** פר-תמונה (כל תמונה שומרת את ההתאמות שלה בנפרד): בהירות, ניגודיות, רוויה, טשטוש, גוון (Hue), שחור-לבן, ספיה, היפוך צבע, חידוד, סיבוב, הפיכה — ו**3 אפקטים אמנותיים מוכנים** (קומיקס / סקיצה / וינטג'׳, שילובי פילטרים מקומיים, לא AI).
  - **כלים כלליים**: בטל/בצע שוב (Ctrl+Z/Y), שכפול רכיב, זום, שקיפות לכל רכיב, צורות (מלבן/עיגול/קו), טקסט עם בחירת גופן/מודגש/נטוי/קו מתאר.
  - **הדפסה** ישירות מהדפדפן לכל מדפסת שמוגדרת ב-Windows (כולל תצוגת רשימת המדפסות הזמינות), עם בחירת גודל הדפסה (8/10/15 ס"מ או A4).
  - שמירת התוצאה כ-PNG בתוך תיקיית `מגנטים-מוכנים` בתוך תיקיית האירוע.

**לגבי עיצוב ב-AI:** אין ליכולת ליצור תמונות AI אמיתיות (כמו "הפוך לקריקטורה") זמינה כרגע בתוך העורך - זה דורש מפתח API חיצוני (כמו OpenAI) שהמשתמש צריך לספק. האפקטים האמנותיים שקיימים (קומיקס/סקיצה/וינטג'׳) הם שילובי פילטרים מקומיים שמדמים סגנון, לא טרנספורמציה מבוססת AI.

## סנכרון חי - מיילים ויומן שמתעדכנים כל הזמן (מומלץ, בלי n8n)

אם `MATON_API_KEY` מוגדר (ראו סעיף Maton למעלה) ו-Gmail + יומן כבר מחוברים ב-Maton,
השרת מסנכרן אוטומטית את מצב המיילים ואת האירועים הקרובים **כל 6 דקות**, כל עוד הוא רץ -
בלי צורך ב-n8n ובלי לחיצה על "רענן".

- מנגנון: `lib/liveSync.js`, נדלק מתוך `server.js` בעליית השרת.
- קצב: משתנה סביבה `LIVE_SYNC_INTERVAL_MIN` (ברירת מחדל 6).
- בדיקת מצב: `GET /api/sync/status` · הפעלה ידנית מיידית: `POST /api/sync/now`.
- בריאות המפתח: `GET /api/maton/health` — אם המפתח פג/לא תקין (401) מוחזר `{ok:false, error}` ומוצג בממשק.
- **סיווג מיילים:** `lib/emailClassify.js` מתייג כל מייל בקטגוריה, ולמיילי חיפוש עבודה גם בתחום מקצועי.
  `data/email-status.json` כולל `jobRelatedCount`, `byCategory`, `byField`, ו-`recentUnread[].{category,jobRelated,field}`.
- הנתונים נשמרים ל-`data/email-status.json` ו-`data/calendar-status.json` (source: `maton-live-sync`).

> אם מפתח ה-Maton פג — צריך מפתח חדש מ-console של maton.ai, ואז `setx MATON_API_KEY "..."` בטרמינל
> של המשתמש (לא בצ'אט) + הפעלה מחדש של השרת. עד אז מונה המיילים/יומן יראה 0.

**חשוב:** הסנכרון עובד רק כשהשרת רץ. כדי שהוא ירוץ תמיד, ודאו שהשרת עולה אוטומטית עם המחשב -
הקובץ `C:\Users\user\run-server.bat` מפעיל אותו, והוא נקרא מ-`startup_local.bat` בכל כניסה למחשב.

## חיבור ל-n8n

### סריקת תיקיות
1. ייבאו את הקובץ `n8n/magnet-studio-scan-workflow.json` ל-n8n (Import from File).
2. הוורקפלואו קורא כל 30 דקות (או בלחיצה ידנית) לנקודת הקצה `http://host.docker.internal:4420/api/n8n/scan` שמחזירה JSON עם רשימת כל האירועים, מספר התמונות והמסגרות.
3. הוא שולח סיכום בחזרה ל-`http://host.docker.internal:4420/api/n8n/notify`, וזה מופיע בלוח הבקרה תחת "אוטומציה · n8n".

### מצב מיילים חי - אופציה 1: Gmail דרך n8n
1. ייבאו את `n8n/magnet-studio-email-workflow.json`.
2. בנוד "שליפת מיילים שלא נקראו" — לחצו על שדה ה-Credential ובחרו "Sign in with Google" (מתחבר פעם אחת לחשבון Gmail שלכם, ישירות דרך n8n - לא צריך הגדרות Google Cloud ידניות).
3. בנוד "בניית סיכום" עדכנו את `REPLACE_WITH_YOUR_EMAIL` לכתובת המייל שלכם.
4. הפעילו את הוורקפלואו (Active) - מרגע זה מצב המיילים בפאנל הצד יתעדכן אוטומטית כל 15 דקות.

אם n8n לא רץ ב-Docker אלא ישירות על המחשב, יש להחליף את `host.docker.internal` ב-`localhost` בכל ה-HTTP Request nodes.

### מצב מיילים חי - אופציה 2: Outlook המקומי (בלי n8n בכלל)
השרת יודע לקרוא ישירות מתוך Outlook המותקן במחשב (COM automation), בלי OAuth ובלי Google Cloud - אבל זה דורש ש-**Outlook יהיה כבר מוגדר עם חשבון מייל במחשב הזה**. אצלך כרגע Outlook מותקן אך **אין בו חשבון מוגדר** - בפעם הראשונה שניסיתי לגשת אליו הוא נתקע במסך "הוספת חשבון" כי אין לו למי להתחבר.

**כדי להפעיל את זה:**
1. פתחו את Outlook ידנית והוסיפו את חשבון המייל שלכם (זה משהו שרק אתם יכולים לעשות - דורש הסיסמה שלכם).
2. אחרי שהחשבון מוגדר, לחצו על "רענון מ-Outlook" בפאנל הצד בלוח הבקרה כדי לבדוק שזה עובד.
3. כדי להפעיל סריקה אוטומטית כל 5 דקות (במקום ידנית בלבד), הריצו את השרת עם המשתנה `ENABLE_OUTLOOK_AUTOSCAN=1`, למשל:
   ```bash
   set ENABLE_OUTLOOK_AUTOSCAN=1 && npm start
   ```
   (אפשר גם להוסיף שורה כזו ל-`הפעלת הסטודיו.bat` אם רוצים שזה יהיה קבוע).

עד שהחשבון יוגדר ב-Outlook, כפתור "רענון מ-Outlook" יחזיר שגיאה ברורה במקום להיתקע.
